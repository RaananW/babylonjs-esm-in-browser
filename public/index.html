No framework. No bundler.

Babylon.js native ES modules

Run the same Babylon.js application three ways. Each demo loads the same index.js; only the import map changes where the Babylon.js modules come from.

Using the latest Babylon.js release: __BABYLON_VERSION__

Local control

Self-hosted

Babylon.js package files are copied into this deployment and served from the same origin as the application.

"@babylonjs/core/": "../@babylonjs/core/" Open self-hosted demo

Package CDN

jsDelivr

The browser imports the pinned Babylon.js packages directly from jsDelivr's globally distributed npm CDN.

"@babylonjs/core/": "https://cdn.jsdelivr.net/npm/..." Open jsDelivr demo

Package CDN

unpkg

The browser imports the same pinned Babylon.js packages directly from unpkg without changing the application code.

"@babylonjs/core/": "https://unpkg.com/..." Open unpkg demo
